## About This Website

A single-page, dark-mode portfolio with a black, lime and yellow palette and no build step or dependencies.

- Notebook-style intro loader that types a short script, "runs" it and reveals the page
- Typewriter hero with an animated *messy data → clean data → forecast* card
- Endless 3D project carousel (drag, click or use the arrow keys)
- Left icon navigation rail with scroll-aware highlighting, plus a scroll-progress bar
- Copy-to-clipboard email button
- Fully responsive, keyboard accessible, and respects `prefers-reduced-motion`

**Built with:** HTML5, CSS3 and vanilla JavaScript. **Hosted on:** GitHub Pages.

### Run it locally

```bash
git clone https://github.com/Yosa03-dat/Portfolio.git
cd Portfolio
# open index.html in your browser, or serve it:
python -m http.server 8000   # then visit http://localhost:8000
```
